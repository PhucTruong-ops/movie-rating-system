# Movie Rating System

## Overview
A web application where users can add movies and give them ratings from 1 to 5.

## Features
- Add a movie with title, genre, and release date
- Rate a movie from 1 to 5
- Edit an existing movie
- Delete a movie
- Validate required fields and rating values
